# Backup do site antigo

Este diretório guarda, para referência histórica, a versão anterior do site
(HTML/CSS/JS estático puro) que ficava na raiz do repositório e era servida
diretamente pelo GitHub Pages.

Não é mais publicado em produção — o site atual é gerado a partir de
[`../site`](../site) e entregue automaticamente na raiz do repositório. Veja o
[README principal](../README.md) para a estrutura completa e o fluxo de
deploy.
